# CrystalREPA — MatterGen

MatterGen with atom-wise representation alignment to frozen MLIP teachers.
See the [repository README](../README.md) for installation, experiments and citation,
and [MatterGen usage](../docs/mattergen.md) for command-line examples.

This package retains the `mattergen` Python namespace. The recommended entrypoint
is `python scripts/mattergen.py` from the repository root, with configurations in
`experiments/mattergen/`.

Based on [Microsoft MatterGen](https://github.com/microsoft/mattergen).
The original MIT license and third-party notices are included in `LICENSE` and
`NOTICE`; file-level attribution is retained in the source.
